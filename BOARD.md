Обновлено: 2026-11-26 (инициализация проекта)

## Паспорт темы P05
- **Название:** «Классный штаб» — школьная панель совета старшеклассников.
- **Подводный камень:** путаница `Date.prototype.getDay()` в JS (`0` = воскресенье, `1` = понедельник ... `6` = суббота); несколько массивов в одном JSON-состоянии (атомарная запись без затирания ключей); обработка `weathercode` и единиц измерения Open-Meteo; запрет персональных данных (телефоны и домашние адреса).
- **Идея защиты:** показать «Сегодня» с `aria-current="date"`, сменить дежурного с сохранением в `localStorage`, показать живую погоду Москвы (Open-Meteo) и переключение на честный фолбэк в `Offline`.

## Схема данных (`localStorage` ключ `p05-class-hq-v1`)

```json
{
  "notices": [

    }
  ],
  "duties": [
    { "weekday": 1, "names": ["Алина", "Тимур"] }
  ],
  "birthdays": [
    { "name": "София К.", "className": "10А", "md": "03-21" }
  ],
  "settings": {
    "theme": "light",
    "glass": "on",
    "workdays": 5,
    "lat": 55.75,
    "lon": 37.62
  }
}
```

### Документация маппинга дней недели
В JavaScript метод `date.getDay()` возвращает:
- `0` — Воскресенье (в школьной сетке 5–6 рабочих дней не участвует; в интерфейсе выводится подсказка о ближайшем понедельнике)
- `1` — Понедельник
- `2` — Вторник
- `3` — Среда
- `4` — Четверг
- `5` — Пятница
- `6` — Суббота (отображается при включении режима 6-дневной учебной недели)
