# Классный штаб (P05)

Интерактивная школьная панель совета класса в монохромной чёрно-белой палитре и стиле прозрачного iOS Liquid Glass, объединяющая график дежурных, доску объявлений, календарь дней рождения и прогноз погоды на завтра для утренней линейки.

**Открыть:** https://dunya2200.github.io/class-hq-dashboard/

## Стек

- HTML5 (семантическая разметка, доступные формы, ARIA-атрибуты)
- CSS3 (Mobile First, CSS Grid и Flexbox, монохромные CSS-переменные, локальный шрифт `fonts/font.otf`, пружинные кривые `linear()`, скользящий индикатор на `clip-path`, трёхуровневый iOS Liquid Glass)
- Vanilla JS (ES6+, DOM API, Fetch API, `localStorage`, Canvas SDF + SVG `feDisplacementMap` с кэшем фильтров)
- SVG (монохромный логотип и спрайт из 24 векторных иконок без использования эмодзи)

## Что умеет

- Показывает сводку дня: текущую дату, сегодняшнюю пару дежурных и ближайших именинников.
- Ведёт доску объявлений класса: создание, редактирование, перенос в архив, восстановление и удаление с контролем лимита длины (80 и 280 символов).
- Строит график дежурных по сетке на 5 или 6 учебных дней с подсветкой сегодняшнего дня (`aria-current="date"`).
- Фильтрует список дней рождения по месяцам и хранит только имя, класс и дату без года рождения.
- Загружает прогноз погоды в Москве (`55.75, 37.62`) на завтра через Open-Meteo API и совет дня через Advice Slip API, отображая состояния загрузки, пустого ответа и офлайн-фолбэка (`data/fallback.json` и `{ "tmax": 12, "code": 2 }`).
- Блокирует отправку номеров телефонов и домашних адресов во всех формах на этапе валидации.
- Переключает светлую и тёмную ч/б темы без мигания при загрузке, а также снижает прозрачность стекла кнопкой доступности (`[data-glass="off"]`).
- Сохраняет все коллекции и настройки в `localStorage` под ключом `p05-class-hq-v1` с защитой от повреждённого JSON и кнопками очистки и восстановления демо-набора.

## Что сделано с помощью ИИ

- Отрисован монохромный векторный логотип `img/logo.svg` без жёстких пиксельных размеров и единый спрайт из 24 SVG-иконок в `index.html`.
- Выполнен рефакторинг двух сложных функций в `script.js` с проверкой на четырёх наборах входных данных: `validateNoPersonalData` (таблица правил `PII_RULES`) и `normalizeWeatherForecast` (нормализация живого ответа Open-Meteo и компактного фолбэка со словарём `WMO_WEATHER_MAP`).
- Добавлен кэшируемый движок преломления Снеллиуса (`filterCache`) для плавающих панелей, прозрачных кнопок и встроенных стеклянных выпадающих меню выбора, а также проверено соответствие требованиям доступности и контраста.

## Известные ограничения

- Приложение является статическим сайтом и сохраняет данные только в `localStorage` конкретного браузера: созданные объявления, дежурные и дни рождения не синхронизируются между устройствами одноклассников.
- Живое оптическое преломление по закону Снеллиуса (`backdrop-filter: url(#...)`) работает только в браузерах на движке Chromium; в Safari (WebKit баг `#245510`) и Firefox (Gecko баг `#1972363`) плавающие панели и кнопки отображаются через кроссбраузерный CSS-уровень Tier 1 (`backdrop-filter: blur()` + френелевский блик).
- Цитата на линейку от публичного Advice Slip API приходит на английском языке, а при отсутствии сети заменяется на русскоязычные фразы из локального резерва `data/fallback.json`.
