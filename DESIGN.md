# DESIGN.md — Контракт дизайн-системы (Ч/Б iOS Liquid Glass)

## 1. Монохромная цветовая схема и типографика

- **Шрифт:** локальный `fonts/font.otf` (`SF Pro Display Light`, подключённый через `@font-face` относительным путём).
- **Палитра:** строгий монохром без цветных акцентов (светлая тема `#0D0D10` на `#ECECEF`/`#FFFFFF`, тёмная тема `#F5F5F7` на `#070709`/`#111114`), переключение выполняется переопределением токенов в `html[data-theme="dark"]`.
- **Логотип и иконки:** монохромный векторный логотип `img/logo.svg` и единый спрайт из 24 векторных иконок (включая `icon-chevron-down` и `icon-check`), эмодзи не используются.

## 2. Применение прозрачного стекла iOS Liquid Glass

- **Слой контента (Слой 1):** фон с мягкой монохромной сеткой (создающей выраженную оптическую рефракцию под стеклом) и сплошные читаемые карточки данных (`content-card`, `duty-day-card`, `notice-card`, `birthday-item`).
- **Слой плавающих элементов и кнопок (Слой 3):**
  1. Верхняя плавающая навигация (`.lg-regular.lg-pill`, `data-lg-refract`), со скользящим `clip-path`-индикатором активной вкладки (без `startViewTransition`).
  2. Нижний док командира (`.lg-regular.lg-pill`, `data-lg-refract`).
  3. Все самостоятельные кнопки, переключатели и триггеры вне стеклянных панелей (`.lg-btn-glass`, `data-lg-refract`): почти прозрачная стеклянная линза с 1px френелевским бликом, размытием и преломлением фона под ней. При наведении используется только плавный физический подъём элемента без свечения вокруг и без курсорного пятна.
  4. Встроенные стеклянные выпадающие меню выбора (`#glass-select-popover`, `.lg-menu`, `data-lg-refract`) для фильтра месяцев и полей форм — вместо системного меню браузера.
  5. Модальные шторки форм (`.lg-thick`, 66–68% плотность, единый круговой `border-radius: 28px` без `corner-shape: squircle` для исключения двойных угловых границ).

Вложенный `backdrop-filter` (Glass-on-Glass) запрещён: кнопки *внутри* шапки, дока, модальных шторок и сегментированных переключателей не несут повторного размытия.

## 3. Трёхуровневая кроссбраузерная архитектура

- **Tier 0:** сплошной высококонтрастный ч/б интерфейс при отсутствии GPU, при `prefers-reduced-transparency: reduce`, `prefers-contrast: more`, `forced-colors: active` и по тумблеру `#lg-reduce-toggle` (`[data-glass="off"]`).
- **Tier 1:** `@supports ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)))` для Safari, Firefox и Chromium; `-webkit-backdrop-filter` указывается первым. Френелевская кромка `1px` рисуется на `::before` через `mask-composite: exclude` без `mix-blend-mode`.
- **Tier 2:** живое преломление по закону Снеллиуса (`n = 1.5168`, выпуклый сквиркл, 4-кратная симметрия квадрантов на Canvas, `color-interpolation-filters="sRGB"`, `filterUnits="userSpaceOnUse"`) включается через JS-проверку `navigator.userAgentData` в Chromium с кэшированием идентичных SVG-фильтров по размерам и пересчётом только в `ResizeObserver` через `rAF`.
